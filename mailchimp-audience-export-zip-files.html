What's in a Mailchimp audience export ZIP (and which CSV is which)

Short answer: when you export an audience, Mailchimp often gives you a ZIP that "contains separate CSV files for each type of email contact (subscribed, unsubscribed, non-subscribed, and cleaned)" (View or Export Your Contacts). The file name of each CSV tells you the contact type. Those files are what a billing audit reads.

How to export an audience

  1. Click Audience. If you have more than one, pick the audience from the drop-down.
  2. Click Export audience.
  3. In the pop-up, click Export CSV. Mailchimp emails you when it's ready (source).
  4. Download the file. Exports stay available in your account for 30 days; reopen them under Audience → More options → Export history (same source).

You can also export a saved segment, a tag (after saving it as a segment), or a group the same way. Owners and Admins are the user levels that can export full audiences (source).

Repeat once per audience if you're auditing the whole account. Mailchimp can't see duplicates across audiences, so one export isn't enough when you have several (About Duplicate Contacts).

What's inside the ZIP

Open the ZIP. You'll typically see one CSV per contact type. Mailchimp says the contact type "appears in the file name of the exported file" (source). Common names look like:

File name patternContact typeCounts toward contact limit?
…subscribed… (and not "unsubscribed" / "non-subscribed")SubscribedYes
…unsubscribed…UnsubscribedYes
…nonsubscribed… / …non-subscribed…Non-subscribedYes
…cleaned…CleanedNo

Billing rules: About Your Contacts. An export of only one type (for example archived contacts) may be a single CSV, not a ZIP (source). Archived contacts are exported separately from active contacts (same source).

If you also have SMS contacts, Mailchimp includes a separate SMS folder with SMS-specific columns such as SMS Phone Number, Program Name and SMS Subscription Status (source).

Columns that matter for a billing audit

Every export includes your audience fields plus contact data Mailchimp collects. Useful columns for counting and deduping (What's included):

  • Email Address — the key used to spot the same person across audiences.
  • EUID — "the unique identifier for a contact on the account level, across all audiences."
  • LEID — "the unique identifier for a contact, specific to an audience."
  • MEMBER_RATING — activity rating; useful when you keep one copy of a duplicate and archive the others.
  • TAGS, NOTES, audience merge fields — context you may want to keep before archiving.
  • OPTIN_TIME / CONFIRM_TIME / LAST_CHANGED — timestamps. IP and location columns (OPTIN_IP, CONFIRM_IP, LATITUDE, LONGITUDE, TIMEZONE, CC, REGION) are included too, so treat the file as personal data.

What an audience export does not include: email engagement metrics (opens and clicks), purchase history, predicted demographics, favorite email client, social profile data, and a complete record of profile updates (What's not included). For GDPR personal-data requests, Mailchimp says to export from the contact's profile instead of using the bulk process (same source).

Unsubscribed and cleaned CSVs: extra columns

The unsubscribed and cleaned files carry the same audience fields as the subscribed file. In real exports they usually add a few status-specific columns, such as UNSUB_TIME, UNSUB_CAMPAIGN_TITLE and UNSUB_REASON in the unsubscribed file (a user quotes UNSUB_CAMPAIGN_TITLE from their export in this Zapier Community thread) and CLEAN_TIME in the cleaned file. Mailchimp's help article doesn't list these columns, so treat the exact set as something to check in your own file. The file name is Mailchimp's documented way to tell the types apart.

The unsubscribed file is the one you want when you plan to archive people who still count toward your bill: Does Mailchimp charge for unsubscribed contacts?

Opening the CSVs without garbled characters

If special characters look wrong in Excel, Mailchimp suggests renaming .csv to .txt and opening with UTF-8 encoding, or pasting from a UTF-8 text editor into Excel and using Text-to-Columns (source). Google Sheets and LibreOffice Calc usually open UTF-8 CSVs cleanly.

FAQ

Why does my Mailchimp export come as a ZIP of several CSVs? Mailchimp separates contact types into different files. One ZIP can contain subscribed, unsubscribed, non-subscribed and cleaned CSVs, with the type in each file name.

Which export file has my unsubscribed contacts? The CSV whose file name includes "unsubscribed". Open that file (or drop the whole ZIP into AudienceTrim) when you want to see who still counts toward your bill after opting out.

Do cleaned contacts appear in the export? Yes, in their own CSV. They don't count toward your contact limit, so a billing audit shows them separately from billable contacts.

How long does Mailchimp keep an export? Contact exports and their CSVs stay available in your account for 30 days. Re-download them from Audience → More options → Export history.
